Portfolio BUT GEII - template HTML
==================================
Ouvrir index.html dans un navigateur.
- Apercu PDF : chaque page d'AC lit docs/ac-<competence>-NN.pdf ; le CV lit docs/cv.pdf.
  Les fichiers fournis sont des exemples : les remplacer en gardant le meme nom.
- Video : placer le fichier dans video/presentation.mp4 (et une image img/video-poster.jpg).
- Remplacer tous les [crochets] et les ACxx.xx par vos informations.
- Placer vos images dans img/ et vos PDF dans docs/.
- Le style est dans css/style.css (palette en variables CSS au debut du fichier).
- Ids des AC : ac-<competence>-NN (ex. ac-concevoir-01.html).
